# 语音大作业

先阅读 `交接报告/语音文字与情绪联合识别项目总结与交接报告.pdf`。

## 打开系统

双击本目录下的 `启动联合界面.cmd`，等待终端出现 Running on local URL，然后打开 http://127.0.0.1:7860 。首次加载模型可能需要几十秒。服务运行期间保留终端窗口，结束时按 Ctrl+C。

本机运行环境位于 `D:\Anaconda\envs\chinese-asr`，已经在 D 盘，无需重复搬运。该启动文件专为当前电脑配置；换电脑请依照 ChineseASR/environment.yml 新建环境。

## 文件在哪里

- `ChineseASR/`：完整可运行工程，包含源码、Git 历史、本地模型、数据、checkpoint、实验结果和课程提交包。
- `ChineseASR/submission/`：课程提交材料；不包含两套大型基础模型，换电脑需按说明下载。
- `交接报告/`：为首次接触项目的人编写的总报告，提供 Word、PDF 和 Markdown 版本。
- `工作记录/`：原工作目录中的上游仓库、脚本、旧测试副本、页面截图和报告排版记录。
- `迁移记录/`：文件校验清单、迁移日志及本机环境快照。

建议完整保留 ChineseASR、交接报告和迁移记录。工作记录属于过程档案，日常运行不需要进入。原 C 盘路径仅保留兼容链接，实际项目与工作文件保存于本目录。
